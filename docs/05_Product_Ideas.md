## 1. 아이디어를 관리하는 방식

새 기능은 이름과 화면보다 먼저 다음 질문으로 살펴본다.

**누구의 어떤 어려움을 해결하는가? 현재 기능으로는 왜 부족한가? 더 작은 실험으로 확인할 수 있는가?**

아이디어의 상태는 가볍게 관리한다.

| 상태 | 의미 |
| --- | --- |
| 후보 | 문제와 기대 효과를 정리했지만 필요성을 확인하지 않았다. |
| 검증 중 | 인터뷰·시안·작은 실험으로 필요성을 확인하고 있다. |
| 채택 | 범위와 선행 조건을 정해 실제 개발 대상으로 옮겼다. |
| 보류·제외 | 현재 필요성이 약하거나 다른 방식으로 해결하기로 했다. |

현재 아래의 아이디어는 모두 ‘후보’다. 나열 순서는 확정된 개발 순서나 출시 일정이 아니다.

## 2. 후보 개요

| 후보 | 해결하려는 문제 | MVP와의 차이 |
| --- | --- | --- |
| 개념 연결 지도와 스킬트리 | 배운 지식의 전체 구조와 다음 방향이 잘 보이지 않는다. | 현재 코스의 간단한 지도를 여러 영역으로 확장한다. |
| 복습 추천과 약한 연결 보강 | 헷갈리는 개념을 언제 어떻게 다시 볼지 모르겠다. | 기본 오답 연결을 넘어 시점·문항을 추천한다. |
| 가벼운 시작 진단 | 이미 아는 내용과 필요한 내용이 섞여 있다. | 공통 추천 코스 대신 시작 위치를 제안한다. |
| 맥락을 아는 AI 튜터 | 정해진 해설로 풀리지 않는 질문이 있다. | 검토된 레슨을 바탕으로 추가 설명을 제공한다. |
| 뉴스·투자 화면과 연결되는 학습 | 배운 개념이 현실에서 어떻게 쓰이는지 연결하기 어렵다. | 정적 가상 사례를 넘어 외부 맥락으로 확장한다. |
| 상황형 미션과 시뮬레이션 | 개별 개념은 알지만 여러 정보를 함께 해석하기 어렵다. | 한 개념의 퀴즈에서 복합 상황의 판단으로 확장한다. |
| 캐릭터·친구와 함께하는 성장 | 혼자 공부할 때 성취와 꾸준함을 나누기 어렵다. | 기본 XP·진행 표시 외의 동기를 시험한다. |
| 목적별 학습 경로 | 청소년·사회초년생의 금융 관심사가 서로 다르다. | 공통 투자 개념 코스에서 생활 목적별로 확장한다. |
| 교육기관·유료 코스 모델 | 반복 학습과 콘텐츠 제작을 지속할 운영 방식이 필요하다. | 개인용 초기 경험을 넘어 구매 주체와 수익모델을 검증한다. |

## 3. 개념 연결 지도와 스킬트리

### 기대하는 경험

사용자는 단순히 레벨이 높아지는 것을 넘어, 자신이 이해한 개념의 연결이 넓어지는 모습을 본다. 예를 들어 ‘기업의 이익 → EPS → PER’이 이어지고, 다른 영역에서 배운 개념과의 연결도 확인한다.

분야별 진행을 통해 “전체적으로 초보자”라는 평가 대신 “ETF 기초는 익숙하고 기업의 숫자는 이제 배우는 중”처럼 자신의 상태를 파악하게 한다.

### 가장 작은 실험

실제 기능을 넓히기 전에 첫 코스의 연결 지도를 두 가지 시안으로 보여준다. 단순 진행 목록보다 위치와 관계를 더 잘 설명할 수 있는지 확인한다.

### 채택 조건과 경계

여러 코스가 생겼고, 사용자가 다음 경로를 고르는 데 어려움을 보일 때 검토한다. 콘텐츠가 적은 상태에서 빈 영역과 잠금 표시만 늘리지 않는다. ‘추천 순서’, ‘실제 선행 지식’, ‘단순 관련 개념’을 같은 연결선으로 취급하지 않는다.

## 4. 복습 추천과 약한 연결 보강

### 기대하는 경험

사용자는 정답을 본 문제를 그대로 다시 푸는 대신, 헷갈린 관계를 다른 맥락에서 확인한다. “PER 문제를 더 풀어보세요”보다 “EPS가 달라지는 경우를 다시 살펴보세요”처럼 구체적으로 안내한다.

### 가장 작은 실험

자동 알고리즘 없이 몇 개의 검토된 변형 문항을 준비해 다음 방문에서 제안한다. 사용자가 이를 유용하게 느끼고, 이전보다 설명을 잘하는지 확인한다.

### 채택 조건과 경계

핵심 개념의 반복 오해가 관찰되고 기본 복습 링크만으로는 부족할 때 검토한다. 문항 풀이 기록이 적은데도 정확한 기억 상태나 숙련도 수치를 추정한 것처럼 표시하지 않는다. 초기에는 단순 규칙이 더 복잡한 모델보다 적절할 수 있다.

## 5. 가벼운 시작 진단

### 기대하는 경험

사용자가 이미 알고 있는 설명을 길게 반복하지 않고, 필요한 시작점을 찾는다. 결과는 순위나 금융 IQ가 아니라 추천 레슨과 확인이 필요한 개념으로 보여준다.

### 가장 작은 실험

선택형으로 소수의 진단 문항을 제시하고, ‘바로 학습하기’와 비교한다. 예를 들어 3~5문항은 시작점 선택에 참고할 수 있지만 전체 금융 역량을 판정하기에는 범위가 제한적이라는 점을 명확히 한다.

### 채택 조건과 경계

사용자 지식 차이가 실제로 크고 공통 코스가 반복적으로 지루하다는 반응이 있을 때 검토한다. 진단을 건너뛸 수 있게 하며, 추천할 코스가 하나뿐이라면 맞춤 분석 기능처럼 포장하지 않는다.

## 6. 맥락을 아는 AI 튜터

### 기대하는 경험

사용자가 현재 레슨에서 이해하지 못한 부분을 물으면, 관련 개념과 수준에 맞춰 추가 설명을 받는다. 예를 들어 ‘EPS를 다시 쉬운 예로 설명해줘’에 대해 현재 학습과 연결되는 설명을 제공한다.

### 가장 작은 실험

자유 대화 전체를 열기 전에 자주 나오는 질문을 수집한다. 정적 추가 해설로 해결할 수 있는 질문과 실제 대화가 필요한 질문을 구분한다. 그다음 검토된 콘텐츠만 대상으로 제한된 설명 기능을 시험한다.

### 채택 조건과 경계

기존 해설로 해결되지 않는 질문이 충분히 쌓이고, 정확성 검토와 비용 관리가 가능한 경우에 검토한다.

AI는 권위 있는 정답 판정자나 투자 추천자가 아니라 학습 보조 역할을 맡는다. 초기 도입에서는 검토된 문항의 정답과 기준을 임의로 바꾸지 않게 한다. 외부 문서나 사용자가 붙여넣은 글 속 지시문은 학습 자료이지 서비스 규칙으로 취급하지 않는다.

최신 사실이나 제도 질문에 답할 근거가 없으면 확인되지 않았음을 드러내야 한다. 필요한 외부 데이터·비용·개인정보 처리 범위도 별도로 정한다. AI 사용 자체가 서비스의 차별화나 학습 효과를 보장한다는 가정은 두지 않는다.

## 7. 뉴스·투자 화면과 연결되는 학습

### 기대하는 경험

사용자는 학습한 용어가 실제로 등장하는 맥락을 읽으며 “이제 이 문장이 이해된다”는 경험을 한다. 이미 배운 개념을 표시하고, 모르는 내용은 관련 레슨으로 연결한다.

### 가장 작은 실험

실시간 뉴스 수집부터 시작하지 않는다. 직접 작성한 가상 경제 기사나 재사용 조건을 확인한 소수 자료에 개념 연결을 붙여 반응을 본다. 특정 날짜의 실제 뉴스처럼 보이는 허구의 제목은 사용하지 않는다.

### 채택 조건과 경계

사용자가 레슨 밖의 문장과 숫자로 연결하고 싶다는 요구를 보일 때 검토한다. 실제 자료를 사용한다면 출처·발행일·내용의 적용 시점과 이용 조건을 확인한다.

뉴스의 사실 설명과 향후 가격에 대한 전망을 구분한다. 기사 하나를 읽고 ‘그러므로 이 종목을 매수’로 이어지는 구조는 이 제품의 목적과 다르다.

증권 앱 화면을 연결하는 기능도 실제 계좌 연동부터 시작할 필요는 없다. 개인 정보가 없는 교육용 화면으로 개념의 위치와 의미를 설명하는 작은 실험이 가능하다.

## 8. 상황형 미션과 시뮬레이션

### 기대하는 경험

여러 숫자나 조건이 함께 주어졌을 때 사용자가 필요한 정보를 고르고, 무엇을 판단할 수 있는지 설명한다. 기본 용어 퀴즈보다 한 단계 넓은 적용 연습을 제공한다.

### 가장 작은 실험

가상 기업 두 곳의 자료를 제시하고 ‘주어진 정보로 확실히 말할 수 있는 내용’을 고르게 한다. 복잡한 시장 엔진이나 장기간 모의 포트폴리오 없이도 상황 판단 미션을 구성할 수 있다.

### 채택 조건과 경계

기본 개념을 이해한 사용자가 더 종합적인 문제를 원할 때 검토한다. 가정과 평가 기준을 먼저 정하고, 미래의 결과를 맞히는 능력보다 근거·조건·위험·불확실성을 구분하는 과정을 평가한다.

더 큰 경제 시뮬레이션을 만든다면 결과가 교육용 모델의 가정에서 나온다는 사실을 명시한다. 현실 시장이 동일하게 움직인다고 암시하지 않는다.

## 9. 캐릭터·친구와 함께하는 성장

### 기대하는 경험

학습 진도에 따라 캐릭터나 개인 공간이 성장하고, 친구와 작은 목표를 함께 달성한다. 경쟁 순위보다 “이번 주에 새 개념 하나씩 서로 설명하기”처럼 학습과 가까운 상호작용을 먼저 검토한다.

### 가장 작은 실험

같은 완료 화면에 ‘배운 개념의 연결’과 ‘작은 캐릭터 성장’을 각각 적용한 시안을 보여준다. 성취감을 느끼는지, 학습 내용을 가리는지 확인한다. 친구 기능은 실제 커뮤니티를 열기 전에 소규모 테스트 그룹의 공동 목표로 실험할 수 있다.

### 채택 조건과 경계

학습 자체의 가치가 확인됐지만 동기 유지에 보완이 필요할 때 검토한다. 꾸미기를 위해 학습이 부수 활동이 되는지, 반복 클릭으로 보상만 얻는 흐름이 생기는지 살펴본다.

청소년이 참여하는 소셜 기능은 공개 프로필, 연락, 신고, 운영 부담을 별도로 검토해야 한다. 아바타 시안을 추가하는 일과 이용자 간 자유 소통을 여는 일의 범위를 같은 것으로 보지 않는다.

## 10. 목적별 학습 경로

### 기대하는 경험

연령 하나로 수준을 단정하지 않고, 실제 학습 목적에 따라 경로를 고른다.

| 경로 후보 | 다룰 수 있는 질문 |
| --- | --- |
| 투자 화면 이해하기 | 주가·시가총액·EPS·PER은 무엇을 의미할까? |
| ETF 시작 개념 | 여러 자산을 묶어 투자한다는 것은 무엇일까? |
| 경제뉴스 읽기 | 금리·물가·환율 뉴스에서 어떤 개념이 연결될까? |
| 첫 월급과 금융 생활 | 비상금·신용·대출 등의 개념을 어떻게 이해할까? |
| 용돈과 돈의 원리 | 저축·이자·복리·물가는 어떤 의미일까? |

### 가장 작은 실험

사용자가 고르는 관심 주제와 실제로 완주하는 주제가 같은지 확인한다. 모든 경로를 구현하기 전에 소개 카드와 짧은 샘플 레슨으로 수요를 살펴볼 수 있다.

### 채택 조건과 경계

공통 코스 이후 서로 다른 목적이 반복적으로 드러날 때 검토한다. 청소년이면 무조건 가장 쉬운 단계, 사회초년생이면 무조건 특정 금융상품 단계로 배정하지 않는다. 제도·세금·계좌 관련 콘텐츠는 별도의 최신성 검토를 거친다.

## 11. 교육기관·유료 코스 모델

### 기대하는 가능성

개인 사용자가 추가 코스를 이용하거나, 학교·동아리·교육 담당자가 학습 프로그램으로 활용하는 경로를 검토할 수 있다. 이는 현재 확인된 구매 수요나 제휴 계획이 아니다.

### 가장 작은 실험

개인 사용자에게는 어떤 추가 학습에 가치를 느끼는지 확인하고, 기관 담당자에게는 실제 수업에서 필요한 사용 방식과 보고 범위를 묻는다. 처음부터 결제·기관 관리·교사 대시보드를 동시에 만들지 않는다.

### 채택 조건과 경계

반복 사용과 콘텐츠 가치가 확인되고, 구매 주체의 요구가 구체화됐을 때 검토한다. ‘재미있다’는 반응과 돈을 지불할 의향은 구분한다.

구독, 코스별 결제, 기관용 이용권은 서로 다른 가설이다. 제휴를 하더라도 교육 내용이 특정 상품 홍보에 의해 좌우되지 않도록 제품 원칙과 운영 기준을 정해야 한다.

## 12. 새 아이디어 기록용 템플릿

아래 양식을 복사해 짧게 추가한다. 모든 항목을 길게 채울 필요는 없다.

```markdown
### 아이디어 이름

상태: 후보 / 검증 중 / 채택 / 보류·제외

사용자 문제:
누가 어떤 상황에서 어려움을 겪는가?

기대하는 경험:
이 기능을 통해 무엇이 달라지는가?

현재 방식으로 부족한 이유:
기존 레슨·해설·복습으로 해결할 수 없는가?

가장 작은 검증:
전체 기능을 만들기 전에 무엇을 보여주거나 시험할 수 있는가?

선행 조건:
콘텐츠, 데이터, 운영, 검토 중 먼저 필요한 것은 무엇인가?

주의할 점:
학습 왜곡, 비용, 개인정보, 정확성, 운영 부담은 무엇인가?

검증 결과와 결정:
무엇을 관찰했고 다음에 어떻게 할 것인가?
```

## 13. 아이디어를 실제 범위로 옮길 때

필요성이 확인되면 해당 아이디어를 ‘채택’으로 바꾸고, [04. MVP](04_MVP.md) 또는 이후 버전의 범위 문서에 최소 구현 범위와 완료 기준을 옮긴다. 현재 학습 구조나 사용자 흐름을 바꾼다면 02·03번도 함께 수정한다.

아이디어의 개수보다 중요한 것은 첫 사용자가 “이제 이해된다”고 느끼는 순간을 만드는 것이다. 기능이 늘어나도 그 경험이 더 좋아지지 않는다면 도입 시점을 다시 검토한다.
