# 0.4.0 콘텐츠 교체 안내

홈의 구조는 유지하며 질문은 핵심 50선 기반 50개로 변경했습니다. 원본은 `08_Core_50_Data.md`이고 `home_prompts.dart`에는 모델·선택 로직·이전 기록 검증용 질문만 남습니다. 본 학습은 개념당 2문항입니다. 아래는 0.3.0 구현 당시의 기록입니다.

# 참여에서 학습으로 이어지는 홈 · 0.3.0

2026-10-07 사용자 요청: 홈에 흥미를 느끼고 실제 학습으로 이어지도록 개선한다. 기존의 짧은 핵심·선택형 상세 설명·작은 숫자 원칙을 유지한다.

## 바뀐 흐름

앱 실행 → 오늘의 한입 질문에 선택 → 짧은 해설 → 관련 레슨의 핵심 화면 → 예시와 퀴즈.

첫 방문에도 홈을 바로 보여준다. 기존 환영 화면과 레슨 소개 화면을 거치지 않고 한입 또는 다음 레슨에서 시작할 수 있다. 로그인은 마이페이지에서 선택한다.

- **오늘의 한입:** 기존 L01~L08의 원리를 바탕으로 만든 별도 질문 8개. 기기의 현지 날짜에 따라 돌아가며 노출한다. 허구의 시세나 뉴스로 표현하지 않는 작은 교육용 예시다.
- **즉시 해설:** 선택 후 짧게 설명하고 관련 레슨으로 연결한다. 해설과 학습 버튼이 보이는 위치로 이동한다. 틀림을 벌점이나 학습 제한으로 만들지 않는다.
- **이어가기:** 미완료 학습이나 복습이 있으면 홈 위에 표시한다. 저장된 단계와 답변을 유지한 채 돌아간다.
- **다음 한 걸음:** 다음 미완료 레슨을 바로 시작한다. 모든 레슨을 완료하면 복습으로 연결한다.
- **궁금한 주제:** 관련 질문으로 다른 레슨을 살펴본다. 추천되지 않은 레슨도 전체 보기에서 자유롭게 선택할 수 있다.
- **복습:** 남은 오답이 있을 때 실제 개수를 보여준다.
- **이번 주 발자국:** 한입 질문에 답하거나 코스 퀴즈를 푼 날짜를 표시한다. 빈 날을 실패로 표시하거나 허구의 연속 기록을 넣지 않는다.

## 데이터와 정확성

`lib/content/home_prompts.dart`가 홈 질문의 원본이다. 각 질문은 기존 코스의 레슨 ID와 연결된다. 예시 금액은 1,000~10,000원 수준이다. 코스의 32개 평가 문항은 변경하지 않았다.

기존 진행 JSON에 선택적 `homeAnswers`를 추가했다. 날짜 → 질문 ID·선택 번호이며 최근 참여일 90개를 보관한다. 이전 버전에 이 필드가 없어도 읽을 수 있다. 저장 실패 시 답한 것으로 처리하지 않고 다시 선택할 수 있다. 같은 날 여러 번 눌러도 한 번만 기록한다.

한입 참여는 XP, 완료 레슨, 코스 정오답, 미해결 오답, 학습 세션을 바꾸지 않는다. 코스의 `FIRST_ATTEMPT`는 해당 코스 문항에 대한 첫 응답이며, 그 개념을 생애 처음 접했다는 뜻은 아니다. 홈 질문은 별도 참여 기록이다.

한입 질문을 이미 답했다면 저장된 질문 ID를 우선 사용한다. 자정과 앱 복귀 때 현지 날짜를 다시 확인한다. 질문 목록을 늘리더라도 저장된 ID는 유지하고, 기존 ID 삭제·변경이 필요하면 저장 데이터의 이전 절차를 먼저 추가한다.

이번 주 표시는 월요일부터 일요일까지이며, 코스 응답의 UTC 시각은 기기의 현지 날짜로 변환한다. 날짜가 미래인 기록은 현재 주 참여 수에 포함하지 않는다. 서버로 보내는 분석·알림·계정 기능을 추가하지 않았다.

## 구현과 검증

- `lib/ui/home_feed.dart`: 한입·즉시 해설·다음 레슨·이어가기·주제 카드·주간 참여.
- `lib/ui/home.dart`: 첫 진입, 검색·전체 과정, 탭 탐색.
- `lib/state/progress.dart`: 선택 저장·복원·주간 날짜 집계.
- `test/home_test.dart`: 기존 데이터 호환, 저장 실패·중복 입력, 날짜별 질문, 90일 제한, XP와 코스 기록 분리, 이어하기, 전체 완료, 320px·1.5배 글자에서 모든 질문·해설 배치.
- 네이티브 통합 테스트: 첫 홈 → 한입 → 해설 → 첫 레슨 완료 → 디스크 복원 → 프로필·로그인 준비 상태 → 학습 지도와 예시.

## 다음에 확인할 제품 가설

이 변경이 재방문을 실제로 늘리는지는 아직 검증하지 않았다. 소수 사용자에게 한입 선택 뒤 관련 레슨을 시작하는지, 첫 레슨을 마치는지, 며칠 뒤 자발적으로 돌아오는지를 확인한다. 질문에는 반응하지만 레슨으로 가지 않는다면 해설 뒤 버튼과 연결 레슨의 첫 화면을 먼저 조정한다. 사용자가 다음 행동을 찾지 못한다면 카드를 더 추가하기보다 행동의 우선순위를 조정한다.
