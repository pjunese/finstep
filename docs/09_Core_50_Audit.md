# 핵심 개념 50선 분류·내용 점검과 적용

점검 기준일: 2026-10-08 · 앱 0.4.0+5

사용자 제공 `50.md`의 항목 50개를 모두 유지했다. 원본은 수정하지 않았고 `docs/archive/50-original.md`에 별도 보존했다. 학습 난이도와 개념의 성격에 따라 7개 묶음으로 재분류했다. 복합 용어(보통주/우선주, 지정가/시장가 등)는 원본처럼 한 항목으로 유지한다.

## 분류 판단

- **주식과 주주의 권리 9개:** 배당·주식 종류·증자·자사주. 무상증자는 밸류에이션보다 자본과 주주 권리의 변화에 가깝다. 유상증자도 함께 배치한다.
- **기업의 실적과 재무 9개:** 매출·영업이익·순이익과 재무 지표. EPS/BPS/ROE는 기업의 이익·자산을 정리하는 값으로 묶었다.
- **주가와 가치평가 3개:** 시가총액·PER·PBR. 주가를 규모·이익·순자산과 비교한다.
- **투자상품과 위험관리 4개:** 채권·ETF·ETN·헤징. 상품 구조와 위험을 함께 이해한다.
- **거래와 시장 제도 9개:** 주문·결제·신용·공매도·시장 안정장치·블록딜·IPO.
- **경제지표와 통화정책 10개:** 금리·물가·환율·통화정책. 경기동행/선행지수는 뉴스 표현보다 경제지표 분류가 적합하다.
- **뉴스와 시장 흐름 6개:** 예상 대비 실적, 계절 랠리, 유동성·실적 장세, 모멘텀. 특히 계절 랠리는 필수 투자 법칙이 아닌 뉴스 해석 용어로 표시했다.

이는 학습을 위한 편집 분류다. 예를 들어 배당성향은 재무 비율이기도 하지만, 배당금·배당수익률과 구분하기 쉽도록 주주 권리에 배치했다. 개념 연결은 분류를 가로질러 탐색할 수 있다.

## 구현 범위

- 50개 개념 = 50개 독립 학습 레슨. 각 레슨의 핵심 한 화면, 작은 예시/비유, 선택형 상세 읽기.
- 각 개념의 가상 뉴스 해석 예시. 실제 시세·실제 기사로 표현하지 않는다.
- 150문항: 본 학습 2문항 + 별도 복습 1문항. 오답은 복습에 남기고 새 복습 문항과 재응답을 구분한다.
- 50개 홈 한입 질문. 코스 문항과 문구를 분리하며 XP와 코스 정오답에 합치지 않는다.
- 7개 분류별 과정, 분류와 검색어의 교집합 검색, 저장 필터, 선택한 개념을 중심으로 관계 탐색.
- 쉬운 산식의 네 개념은 기존 작은 숫자 조작을 연결. 나머지는 가상 뉴스 상황으로 개념을 확인한다.
- 원본 번호는 K01~K50/C50_01~C50_50에 보존. 추천 학습 순서는 분류별로 다르며 레슨을 잠그지 않는다.

## 기존 기록 보존

학습 파일명은 `progress-v1.json`을 유지하고 내부 스키마를 2로 확장한다. 버전 1 파일은 이전 콘텐츠로 유효성을 확인한 후 전체를 `legacy`에 보존한다. 완료·저장·오답·응답·미완료 위치·홈 참여 기록을 삭제하지 않는다. 새 학습 진행률은 0/50에서 별도로 시작하고 이전 완료 XP는 합산한다. 같은 개념에 대응하는 저장 항목은 새 카드에도 연결한다.

읽을 때는 파일에 쓰지 않는다. 이후 정상 저장이 성공할 때 새 구조로 저장하고 원본 전체는 중첩 기록과 `.backup`에 남긴다. 실패·손상·미지원 버전은 자동 초기화하지 않는다. 마이 → 학습 기록에 이전 과정의 완료·XP·응답·저장 개념·보던 레슨을 표시한다. 이전 레슨을 새 과정에서 완료한 것으로 간주하거나 이어서 푼 것으로 기록하지 않는다.

## 검증

- 콘텐츠 원본과 생성 파일 일치, 정확히 50개 항목·7개 분류·150문항, 참조 연결 검사.
- 전체 과정 최초 완료/반복 보상, 오답/새 문항 복습, 저장 실패/동시 입력, 구버전 기록 이전 검사.
- 전체 50개 핵심·예시·퀴즈·피드백 및 홈 질문을 320px/글자 1.5배에서 검사.
- 단위·위젯 자동 검사 44개 통과. iPhone 16e(iOS 26)와 Android Pixel 7(API 36) 네이티브 통합 테스트도 통과했다.
